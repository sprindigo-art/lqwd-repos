| Boundary | Description |
|----------|-------------|
| per-backend rows → unified model | LND vs LDK column differences must be isolated to one mapper; a leak (`any`) propagates wrong shapes app-wide. |
| server read → rendered page | The status page imports server-only DB modules; a `"use client"` slip would leak DB access / strings to the client bundle. |
| sat integer → display | Balances must convert only via the AFM-002 formatter at render; in-mapper or in-page math reintroduces AFM-002 drift. |
