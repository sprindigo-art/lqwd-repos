## Copywriting Contract

All control text is lowercase-in-source, rendered uppercase via CSS (existing convention). Honest states are verbatim-locked from RESEARCH/CONTEXT.

| Element | Copy |
|---------|------|
| Primary CTA (collapsed toggle) | `EXPORT COMMANDS` |
| Primary CTA (expanded toggle) | `HIDE COMMANDS` |
| Per-step copy button | `COPY` → success `COPIED` (revert after ~1.5s) |
| Copy-all button | `COPY ALL` → success `COPIED` (revert after ~1.5s) |
| Copy failure (locked, never silent — Pitfall 6) | Button shows `COPY FAILED`; helper line below: `copy failed — select the text manually` |
| Step 1 header | `step 1 — verify (read-only)` |
| Step 2 header | `step 2 — {action}` (e.g. `step 2 — close`, `step 2 — bump fee`) |
| Safety line prefix (D-05, visible UI render) | `safety:` in warn tint, note body in muted text; same wording repeated as `#` comments in copyAll |
| Validation-failure state (locked) | `params failed validation — export withheld` (no partial command ever renders) |
| LDK unsupported state (locked, D-01 honesty) | `not supported on LDK — manual procedure` + line `coordinate with the LSPD operator` (full params still echoed as context) |
| Rebalance placeholder (locked, D-07) | `rebalance execution is operator/AI-managed — no generated command yet` (full params echoed; no fake runnable command) |
| Timelock honesty comment (Pitfall 3) | `# csv_delay (force-close lock) is shown by step 1 — the warehouse does not carry it` |
| Empty state | None rendered — the EXPORT control is **absent** on suppressed cards (null action, T-04-16), `investigate` cards, and `update_fee` cards (Phase 6 prong). Absence IS the signal; no placeholder, no disabled button |
| Destructive confirmation | **None by design (D-03 locked).** Expanding is the deliberate act; commands are inert text; the real gate is the operator's node shell. No acknowledge step, no modal, no reveal gate |

## Component Contract (phase-specific)

### EXPORT control (toggle)

- One control per exportable card (`suggestedAction !== null && type ∈ {close_channel, rebalance, remediate_pending}`), mounted at the bottom edge of the existing suggested-action box on both surfaces (`InsightCardRow`, console Active Signals insight rows) — **one component, both mounts** (D-01).
- Chrome: `buttonVariants({ variant: "outline", size: "sm" })` + `font-mono text-xs font-semibold tracking-[0.14em] uppercase` — the exact `ExportButton.tsx` voice, minus the icon.
- A real `<button>` with `aria-expanded` + `aria-controls={blockId}`; expand/collapse is **instant** (no animation — `FleetPendingBoard` precedent; nothing to gate on `prefers-reduced-motion`).

### Expanded block (`CommandExport` client leaf)

Renders directly below the suggested-action box, inside the card row width (`mt-2`, never escaping `px-4` card padding). Server Components build the `ExportBlock` strings; the leaf only owns expand + copy state.

Anatomy, top to bottom (D-04/D-05/D-06):

1. **Context lines** — mono 12px, `text-foreground/60`, key/value grammar identical to the existing params rows (`gap-3`, key in `text-foreground/45`, value `tabular-nums`). Sat values via `formatSats` (UI/comments only — bare commands carry raw integers).
2. **Safety lines** — `safety:` prefix mono semibold warn-tint (`text-status-warn`), body `text-foreground/60`. Mirrors the existing `SUPPRESSED — reason` grammar.
3. **Step sections** — each: header row (`step N — …` label, mono semibold `tracking-[0.14em]` `text-foreground/60` uppercase; `COPY` button `ms-auto`) above a `<pre>` block: `rounded-[3px] border border-border bg-muted/40 px-3 py-2 font-mono text-xs leading-5 overflow-x-auto whitespace-pre`. Comment lines inside the `<pre>` render `text-foreground/45`; command lines full foreground.
4. **Honest-state line** (LDK / rebalance / validation-withheld) — replaces step 2's `<pre>` with the locked copy as mono semibold uppercase `tracking-[0.06em]` text; params context above still renders.
5. **Footer row** — `COPY ALL` button (same outline chrome), right-aligned.

Copy feedback: button label swaps to `COPIED`/`COPY FAILED` in place (ok/warn tint), announced via `aria-live="polite"`; no toast, no icon.

### Hard rules (from research, binding on executor)

- Per-step COPY copies the **bare command only**; COPY ALL copies the full annotated block including `#` comments (D-02/D-04).
- No commas/formatted numbers inside bare command strings (Pitfall 8); raw integers only.
- Aliases and any card-sourced string entering comments pass `sanitize.ts` first (Pitfall 2).
- No export UI of any kind on suppressed or `update_fee`/`investigate` cards (Pitfall 5).
- `ActiveSignalsPanel` stays a Server Component; only the leaf is `"use client"` (Pattern 3).
