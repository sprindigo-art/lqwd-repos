## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Lightning graph aliases → LLM prompt | Attacker-controllable strings enter the prompt |
| Browser → narrate server action | Client-supplied scope params |
| LLM output → rendered page | Untrusted model text reaches the DOM |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-19 | Tampering | Prompt injection via peer aliases | mitigate | Aliases delimited as data in prompt; output rendered plain text only; narrative path structurally cannot write params (blast radius = cosmetic) |
| T-04-20 | Elevation of privilege | LLM producing/altering numeric params | mitigate | narrateCards returns prose only — no parsing path; ap12 cards locked to info/null-action by schema superRefine; tests assert |
| T-04-21 | Tampering | Client-supplied cards as prompt input | mitigate | Server action recomputes cards server-side; action signature has no card parameter; pubkey regex-validated |
| T-04-22 | Information disclosure | ANTHROPIC_API_KEY in client bundle | mitigate | server-only on provider/narrative; lazy import behind env gate; client leaf only calls the action |
| T-04-23 | Cross-site scripting | LLM output rendered as HTML | mitigate | Plain-text rendering, no dangerouslySetInnerHTML/markdown; grep assertion |
