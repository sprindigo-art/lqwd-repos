schema.ts defines, per RESEARCH §Card Schema verbatim semantics:
- `CARD_SCHEMA_VERSION = 1` (z.literal(1) in the schema).
- `SeveritySchema = z.enum(["critical","warn","info"])` (D-01 — scorecard taxonomy, no new values).
- `DetectorIdSchema = z.enum([...])` with members: `ap11_close_storm`, `ap12a_conn_exhaustion`, `ap12b_serialization`, `htlc_timeout_fc`, `fee_raise`, `fee_lower`, `channel_close_candidate`, `rebalance_partner_failure`, `rebalance_degraded`, `fee_stepdown`, `fleet_close_cluster`, `stuck_fc_past_maturity`, `stuck_sweep`, `stuck_open`.
- `CardTargetSchema` — discriminated union on `kind`: `node`; `channel` {chanId: string|null, channelPoint: string|null, remotePubkey: string|null}; `sweep` {outpointTxid: string, outpointOutputIndex: number}; `fleet` {pubkeys: string[]}.
- `CardEvidenceSchema` — {metric: string, observed: number, threshold: number, unit: string, window: string, asOf: ISO string (z.string(), NOT z.date() — JSON round-trip for Phase 6 canonical signing), deepLink: string, detail: optional record of string|number}.
- `SuggestedActionSchema` — discriminated union on `type` (D-03): `update_fee` {chanId, channelPoint, currentPpm, suggestedPpm, baseFeeMsat, timeLockDelta}; `close_channel` {chanId, channelPoint, force: boolean}; `rebalance` {partnerPubkey, amountSat, direction: "out"|"in"}; `remediate_pending` {case: "bump_fee"|"restart_procedure"|"aged_funding", channelPoint: string|null, outpointTxid: string|null, suggestedSatPerVbyte: number|null}; `investigate` {params: z.object({}).strict()} (empty object, NEVER undefined — uniform canonical signing surface).
- `InsightCardSchema` — {schemaVersion, id: string, severity, node: {pubkey, alias: string|null, backend: z.enum(["lnd","ldk"])} nullable, target, signal: DetectorIdSchema, evidence, suggestedAction: SuggestedActionSchema.nullable(), suppressed: {active: boolean, reason: string|null}, provenance: z.enum(["deterministic","llm-inference"]), rateLimitGuidance: string|null}.
- `.strict()` on EVERY object level — additions are breaking changes by design.
- `.superRefine` enforcing: (a) D-12 — `provenance === "llm-inference"` ⇒ `severity === "info"` AND `suggestedAction === null`; (b) `node === null` ⇔ `target.kind === "fleet"`.
- Export `InsightCardArraySchema = z.array(InsightCardSchema)`.

types.ts re-exports the inferred types (`InsightCard`, `CardEvidence`, `SuggestedAction`, `CardTarget`, `Severity`, `DetectorId`), `CARD_SCHEMA_VERSION`, and documents the dedupe-id rule in the banner: `id = "${signal}:${node?.pubkey ?? "fleet"}:${targetKey}"` where targetKey = chanId ?? channelPoint for channels, `${outpointTxid}:${idx}` for sweeps, `"node"` for node targets, and `pubkeys.sort().join("+")` plus the cluster hour bucket for fleet cards. Banner also states the raw-units invariant (AFM-002 formatter applies at render only) following scorecard/types.ts style.</action>
