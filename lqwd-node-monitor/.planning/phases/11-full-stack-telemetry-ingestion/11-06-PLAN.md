<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fileserver to node (scp) | Distributed payload is untrusted-channel content; must carry NO secret |
| node collector to nodemon DB | A compromised node must not write another host's rows |
| procfs/RPC output to SQL | Probe output crosses into INSERTs; must be parameter-bound |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-11-15 | Tampering/Elevation | shell/SQL injection via subprocess+probe | mitigate | argv (list) invocation, never shell=True; psycopg2 parameter placeholders, never f-string SQL |

| T-11-SC | Tampering | pip installs | mitigate | psycopg2-binary + python-dotenv already on the live fleet (RESEARCH Package Legitimacy Audit: no NEW registry packages); pip runs node-side from the pinned requirements.txt only |
