read_since(source_key, path, cursors) -> (lines: list[str], updated_cursors: dict)
  - complete lines only; offset parked at last "\n"+1
  - inode-match AND size>=offset  -> resume from saved offset
  - inode-change OR size<offset    -> rotation (drain), reset near 0
  - no cursor (first sight)        -> seed offset = max(0, size - INITIAL_TAIL_BYTES)
  - bounded by MAX_BYTES_PER_TICK with a log() truncation line
cursor dict shape: {path, inode, offset, size}
extract_events(...) capture gate: a line is captured iff _classify returns a non-null config match
tier gating (tier = the matched config row's `classification` column value info|warn|critical; there is NO separate `tier` column): info -> ZERO exemplars (aggregate count still bumped); warn -> capped KEEP_N; critical -> more
_normalize: applies _RE_IP_PORT ("<addr>") so per-peer lines collapse to one signature
