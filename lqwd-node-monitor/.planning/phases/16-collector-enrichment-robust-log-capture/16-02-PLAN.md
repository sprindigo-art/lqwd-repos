| node filesystem -> collector | Untrusted, high-volume log bytes read from `/lnd/...` (read-only to collector) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-01 | Tampering/Integrity | `.log-cursors.json` | mitigate | Atomic `os.replace` write; validate inode AND size>=offset on read; prune unresolved source_keys (Pitfall 8) — a killed tick can never corrupt or skip |
| T-16-06 | Tampering | artifact_path glob resolution | mitigate | Globs resolved ONLY from owner-seeded `service_inventory` values, never from log content; confine to configured dirs |
| T-16-07 | DoS / availability | bounded per-tick read | mitigate | `MAX_BYTES_PER_TICK` cap with a LOGGED truncation + deferred remainder — a burst cannot make one tick read unbounded memory |
| T-16-04 | Elevation of Privilege | SELECT-only boundary | mitigate | Cursor is LOCAL node state; zero new warehouse write/grant added (grep asserts no `GRANT ... service_inventory`) |
| T-16-SC | Tampering | pip installs | accept | Stdlib only (`glob`,`gzip`); `zstandard` explicitly NOT added |
