<objective>
Build the COL-02 read layer + retire the `ap12-advisory.ts` LLM fallback:
`getPgHealth` reads `pg_health` latest-per-host (DISTINCT ON), and a PURE
`derivePgHealthVerdict` computes the AP-12a-vs-b discriminator (high
`serialization_40001_count` + low `too_many_clients_count` ⇒ AP-12b; high
`too_many_clients_count` ⇒ AP-12a) and the connection-saturation band from RAW
counters — with the 40001 rate promoted benign→ap12 only at ≥10× baseline
(BP-005), all at read time (D-14). Then replace the LLM advisory with a
deterministic detector that reads these counters + PG-log signatures, preserving
the frozen `ap12a_conn_exhaustion`/`ap12b_serialization` signal ids and the
`AP12_NO_DATA_PLACEHOLDER` no-data contract.

Purpose: makes AP-12 detection deterministic and removes the LLM stopgap the
module itself flags for retirement.
Output: tested pg-health reader + a deterministic detector honoring the contract.
</objective>
