  <action>
    Append 8 new `pgTable` defs to nodemon.ts under a new "Phase 15 — data-collection
    expansion" section header comment, all snake_case DB ↔ camelCase TS. Every FACT table
    gets `id: uuid().primaryKey().defaultRandom()`, `hostId: text().notNull()` (RLS axis),
    `collectedAt: timestamp({withTimezone:true}).notNull()`, RAW columns only (NO severity /
    band / stale column — D-06b/D-14), and the TWO shipped indexes: `(hostId, collectedAt.desc())`
    + `(collectedAt)`.

    Tables and columns:

    (1) `service_log_events` (raw exemplar fact): serviceName text, nodePubkey text (nullable —
    host-level services), level text, message text, contextLines text (the ±5 lines, D-01 —
    resolves Open-Q2 to option (a): a self-contained text column, NO child/join), signature text
    notNull, classification text, configId uuid (NULLABLE — the id of the `log_patterns_config`
    row the collector matched at classify time; NULL for unmatched / "other" lines. This is the
    read-time SUPPRESSION KEY: the reader joins `log_patterns_config` on this primary key so
    `suppress` is resolved per matched PATTERN, not per coarse `classification`. Storing the
    matched-pattern identity is REQUIRED because a classification does NOT uniquely determine
    suppress — the `benign` class holds both suppress=true BP-rows and the suppress=false
    `SQLSTATE 40001` sibling, and `critical` holds 5 sibling rows; a classification join would
    invert suppression (BP-001 leaks) and fan out rows (a critical event rendered 5×). config_id
    keeps D-04 read-time tunability: change `config.suppress` and reads re-filter with no
    re-collection. It is a raw identity pointer — NOT a severity/band/verdict — consistent with
    the existing classification column and D-14-safe), sourcePath text. Indexes:
    (hostId, collectedAt.desc()), (collectedAt), plus (hostId, signature) index to back
    exemplar-per-signature retention.

    (2) `log_patterns` (aggregate): signature text notNull, serviceName text, firstSeen timestamptz,
    lastSeen timestamptz, countWindow bigint, sampleMessage text, classification text. Add a UNIQUE
    constraint on (hostId, signature) to back the D-03 ON CONFLICT upsert. Index (hostId, lastSeen.desc()).

    (3) `log_patterns_config` (DIMENSION, mirror serviceInventory — NO collectedAt, SELECT-only role):
    id uuid pk defaultRandom, matchExpression text, service text, level text, classification text,
    suppress boolean, note text.

    (4) `host_metrics_ext` (deep-VM scalar fact): ctxt bigint, intr bigint, cachedKb/buffersKb/dirtyKb/
    writebackKb/slabKb/sreclaimableKb bigint, pgfault/pgmajfault/pswpin/pswpout/oomKill bigint,
    tcpRetransSegs/tcpOutSegs/tcpInSegs/tcpActiveOpens/tcpAttemptFails bigint, socketsTotal/tcpEstab/
    tcpTimeWait integer, fdAllocated bigint, fdMax bigint, procsRunning/procsBlocked integer,
    failedUnitsCount integer, clockOffsetSeconds numeric (nullable — honest no-data if chrony absent),
    nproc integer, entropyAvail integer, btime bigint.

    (5) `host_cpu_core` (CHILD fact, key coreIndex): coreIndex integer, userJiffies/niceJiffies/
    systemJiffies/idleJiffies/iowaitJiffies/irqJiffies/softirqJiffies/stealJiffies/guestJiffies bigint.
    Composite index (hostId, coreIndex, collectedAt.desc()) + (collectedAt).

    (6) `host_disk_io` (CHILD fact, key device): device text, readsCompleted/sectorsRead/writesCompleted/
    sectorsWritten/iosInProgress/msDoingIo bigint. Composite index (hostId, device, collectedAt.desc())
    + (collectedAt).

    (7) `host_net_iface` (CHILD fact, key iface): iface text, rxBytes/rxErrs/rxDrop/txBytes/txErrs/txDrop/
    txColls bigint. Composite index (hostId, iface, collectedAt.desc()) + (collectedAt).

    (8) `pg_health` (fact, COL-02): datname text, maxConnections/activeConnections/numbackends integer,
    xactCommit/xactRollback/deadlocks bigint, tooManyClientsCount/serialization40001Count/fatalCount bigint,
    blockedQueries integer, slowQueryGt1s integer, statsReset timestamptz (Pitfall 7 — reset boundary for
    read-time Δ clamp). NO a/b verdict column — derived at read (D-14).

    Also extend the EXISTING `hostStorage` table with three ADDITIVE nullable columns (research Open-Q4):
    inodesTotal bigint, inodesUsed bigint, inodesFree bigint. Additive-nullable so the shipped
    host-storage reader + its tests stay green.

    classification stays a plain `text` column (NOT a pgEnum) so it is SQL-tunable per D-05.
