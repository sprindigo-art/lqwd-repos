  <behavior>
    - `clampCounterDelta(prev, curr, prevReset?, currReset?)`:
      - Normal case curr≥prev, same reset stamp ⇒ returns curr−prev.
      - curr<prev (counter went backwards ⇒ reset) ⇒ returns curr (treat as fresh baseline, never negative).
      - currReset moved (differs from prevReset) ⇒ returns curr (reset boundary), even if curr≥prev.
      - prev null/undefined (no prior sample) ⇒ returns null (no rate derivable yet, honest no-data).
      - Result is ALWAYS ≥0 or null; never negative.
  </behavior>
