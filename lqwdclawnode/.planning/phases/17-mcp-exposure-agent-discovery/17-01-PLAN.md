<objective>
Make the existing MCP server reachable under a clean public path (`/v1/mcp`) through Caddy, add an unauthenticated `/v1/discovery` JSON catalog that tells agents how to onboard, and enrich the `/v1/internal/accounts/register` response with a `next_steps` block so any agent that registers self-orients without reading human docs.
</objective>

<goal_backward_check>
An MCP-aware agent must be able to:
1. `curl https://api.lqwdclaw.bot/v1/discovery` → read `mcp_url`, `registration_url`, `tier_matrix`
2. `POST /v1/internal/accounts/register` → receive `api_key` + `next_steps.mcp_url`
3. Connect its MCP client to `mcp_url` with that `api_key` → see the tool catalog
4. Invoke one billed tool → credits debited, response streams back

No human-authored docs should be required between steps 1–4.
</goal_backward_check>

<action>
Context: MCP server currently mounts at `/v1/internal/mcp` (main.go:354) wrapped in the CF Access middleware. Its internal billing/auth uses `Authorization: Bearer lqwd_...` API keys — self-contained, NOT X-Internal-Auth. The `/v1/internal/*` prefix in the Caddy layer injects `X-Internal-Auth`, which is wasted on MCP traffic and conflates two different auth models.

Goal: expose MCP at `/v1/mcp` as the public surface while keeping `/v1/internal/mcp` as an internal alias so nothing existing breaks.

**Step 1.1 — Add a sibling route in `cmd/lnd-gateway/main.go`.**

Find the existing line (~line 354):
```go
mux.Handle("/v1/internal/mcp", cfMw(mcpSrv.Handler()))
```

Immediately AFTER it, add a new mount that reuses the same handler but skips the CF Access middleware (MCP has its own API-key auth inside `mcpSrv.Handler()`):
```go
// Public MCP endpoint — MCP server handles its own Bearer API-key auth
// (lnd-gateway/internal/mcpserver/server.go:48-62). External agents hit
// this path through Caddy at api.lqwdclaw.bot/v1/mcp.
mux.Handle("/v1/mcp", mcpSrv.Handler())
mux.Handle("/v1/mcp/", mcpSrv.Handler())
```

Rationale for two mounts: Go's `http.ServeMux` treats `/v1/mcp` and `/v1/mcp/` as distinct — MCP Streamable HTTP clients may hit either depending on trailing-slash normalization. Two mounts is cheaper than a catch-all redirect.

**Step 1.2 — Exempt `/v1/mcp` from the Bearer-auth middleware in `internal/middleware/auth.go`.**

Current health-exemption block (~line 28):
```go
if r.URL.Path == "/v1/health" || r.URL.Path == "/v1/health/detailed" {
    ctx := context.WithValue(r.Context(), tokenLevelKey, TokenNone)
    next.ServeHTTP(w, r.WithContext(ctx))
    return
}
```

Add a NEW check BEFORE the L402 prefix check (~line 36), mirroring the L402 pattern:
```go
// MCP endpoint uses its own API-key auth (not Bearer)
if strings.HasPrefix(r.URL.Path, "/v1/mcp") {
    ctx := context.WithValue(r.Context(), tokenLevelKey, TokenNone)
    next.ServeHTTP(w, r.WithContext(ctx))
    return
}
```

**Step 1.3 — Exempt `/v1/mcp` from the rate-limit middleware in `internal/middleware/ratelimit.go`.**

Current exemption (line 40):
```go
if r.URL.Path == "/v1/health" || r.URL.Path == "/v1/health/detailed" {
    next.ServeHTTP(w, r)
    return
}
```

Extend:
```go
if r.URL.Path == "/v1/health" || r.URL.Path == "/v1/health/detailed" ||
    strings.HasPrefix(r.URL.Path, "/v1/mcp") {
    next.ServeHTTP(w, r)
    return
}
```

Rationale: MCP tool calls have their own billing/budget + per-agent daily caps via the accounts system. Double-layering gateway rate-limit on top would throttle legitimate MCP traffic; the billing layer is the correct enforcement point.

Verify `strings` is already imported in ratelimit.go; if not, add it.
</action>

```go
// Discovery returns a public catalog describing how agents onboard.
// No auth required. Caddy allowlists this path; see scripts/Caddyfile.
//
// The response shape is stable — external agent harnesses are expected to
// consume it programmatically. When fields are added, do so additively.
func (d *Dependencies) Discovery(w http.ResponseWriter, r *http.Request) {
	base := "https://api.lqwdclaw.bot"

	tierMatrix := []map[string]any{
		{
			"tier":                1,
			"registration_grant":  accounts.DefaultTier1GrantSats,
			"daily_spend_cap":     accounts.Tier1DailySpendCap,
			"channel_faucet":      true,
			"notes":               "Default tier on registration. Self-service.",
		},
		{
			"tier":                2,
			"registration_grant":  accounts.DefaultTier2GrantSats,
			"daily_spend_cap":     accounts.Tier2DailySpendCap,
			"channel_faucet":      true,
			"notes":               "Upgrade available after sustained usage.",
		},
		{
			"tier":                3,
			"registration_grant":  nil,
			"daily_spend_cap":     nil,
			"channel_faucet":      nil,
			"notes":               "Operator-granted. Contact operator.",
		},
	}

	middleware.WriteJSON(w, http.StatusOK, map[string]any{
		"ok": true,
		"data": map[string]any{
			"service":          "lqwdclaw-nodeops",
			"mcp_url":          base + "/v1/mcp",
			"registration_url": base + "/v1/internal/accounts/register",
			"l402_endpoints": []string{
				base + "/v1/l402/node-stats",
				base + "/v1/l402/network-analytics",
				base + "/v1/l402/promo",
			},
			"docs_url":     "https://lqwdclaw.bot/for-agents",
			"tier_matrix":  tierMatrix,
			"example_curl": `curl -X POST ` + base + `/v1/internal/accounts/register -H "Content-Type: application/json" -d '{"name":"my-agent"}'`,
		},
	})
}
```

In `scripts/Caddyfile`, add two new `handle` blocks BEFORE the existing catch-all `handle {}` block (which is currently at ~line 70).

**Step 4.1 — Insert the MCP block AFTER the existing `handle /v1/internal/*` block (around line 53) and BEFORE `handle /v1/health`:**

```caddyfile
    # MCP endpoint — API-key auth handled inside the gateway. Do NOT
    # inject X-Internal-Auth here (MCP uses its own Bearer scheme).
    # Streaming tool calls can run long, so override the global write
    # timeout for this path only.
    handle /v1/mcp* {
        reverse_proxy 127.0.0.1:7778 {
            header_up X-Forwarded-For   {http.request.header.CF-Connecting-IP}
            header_up CF-Connecting-IP  {http.request.header.CF-Connecting-IP}
            header_up CF-Ray            {http.request.header.CF-Ray}
            transport http {
                read_timeout  120s
                write_timeout 120s
            }
        }
    }
```

Note: `/v1/mcp*` (no slash) matches both `/v1/mcp` and `/v1/mcp/...` in Caddy's glob matcher.

**Step 4.2 — Insert the discovery block BEFORE the catch-all:**

```caddyfile
    # Public agent-discovery catalog — no auth, cached at CF edge

            header_up CF-Connecting-IP  {http.request.header.CF-Connecting-IP}
            header_up CF-Ray            {http.request.header.CF-Ray}
        }
    }
```
