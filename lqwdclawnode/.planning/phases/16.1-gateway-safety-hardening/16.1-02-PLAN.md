<action>
In `lnd-gateway/internal/handlers/write.go`, replace the execution block in `SendPayment()` (everything after the budget check, starting around line 244) with the confirmation flow pattern.

**Remove** (lines ~244-278):
```go
// Execute payment (mock or real)
var resp map[string]any
var status int
if d.MockMode {
    resp = mock.SendPayment(req.PaymentRequest, amount)
    status = http.StatusOK
} else {
    var err error
    resp, err = d.LND.SendPayment(r.Context(), lnd.SendPaymentRequest{
        PaymentRequest: req.PaymentRequest,
        AmountSats:     req.AmountSats,
        TimeoutSeconds: 60,
        FeeLimitSat:    req.FeeLimitSats,
    })
    if err != nil {
        resp = lndErr(err)
        status = http.StatusBadGateway
    } else {
        status = http.StatusOK
    }
}
respBytes, _ := json.Marshal(resp)
middleware.WriteJSON(w, status, resp)

d.Idempotency.Store(req.IdempotencyKey, "/v1/payments/send", status, string(respBytes))
d.Audit.Log(audit.Entry{
    Endpoint:     "payments_send",
    Method:       "POST",
    TokenLevel:   tokenLevelStr(r),
    ResponseCode: status,
    AmountSats:   amount,
    OpType:       "payment",
    IdempotKey:   req.IdempotencyKey,
    RequestID:    middleware.GetRequestID(r.Context()),
})
```

**Replace with** (confirmation flow matching OpenChannel pattern):
```go
// Create confirmation (destructive operation — must be confirmed by admin)
desc := fmt.Sprintf("Send %d sat Lightning payment", amount)
reqBody, _ := json.Marshal(req)
op := d.Confirm.Create("/v1/payments/send", desc, string(reqBody), amount)

resp := map[string]any{
    "ok":                    false,
    "confirmation_required": true,
    "operation_id":          op.ID,
    "description":           op.Description,
    "amount_sats":           amount,
    "expires_at":            op.ExpiresAt,
}
respBytes, _ := json.Marshal(resp)
middleware.WriteJSON(w, http.StatusAccepted, resp)

d.Idempotency.Store(req.IdempotencyKey, "/v1/payments/send", http.StatusAccepted, string(respBytes))
d.Audit.Log(audit.Entry{
    Endpoint:     "payments_send",
    Method:       "POST",
    TokenLevel:   tokenLevelStr(r),
    RequestBody:  string(reqBody),
    ResponseCode: http.StatusAccepted,
    AmountSats:   amount,
    OpType:       "payment",
    IdempotKey:   req.IdempotencyKey,
    RequestID:    middleware.GetRequestID(r.Context()),
})
```

Note: The actual payment execution will happen when an admin confirms the operation via the existing `/v1/confirm/{id}` endpoint, which already handles dispatching confirmed operations to LND. The confirm handler in `write.go` (or wherever confirmations are executed) already has the pattern for executing the stored request body against LND.

If `write_test.go` exists and has SendPayment tests that expect `200 OK` responses, update them to expect `202 Accepted` and `confirmation_required: true` in the response body.
