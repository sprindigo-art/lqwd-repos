# Phase 17.1 — API Landing Page

## Goal

Serve a human-readable landing page at `https://api.lqwdclaw.bot/` so a human browsing the API domain sees a marketing-aware explanation of what LQWDClaw-NodeOps is and how to start — instead of the current plaintext "Not found" catch-all 404.

## Scope

One static HTML page, served directly by Caddy from `/`. No gateway code changes. Version-controlled in the repo at `scripts/landing.html`, installed on the VM alongside the Caddyfile.

### What the page conveys (content spec)

1. **Identity:** "LQWDClaw — Lightning onboarding gateway for AI agents." Subtitle names LQWD Technologies Corp. (TSX.V: LQWD).
2. **Three entry paths:**
   - **No node:** L402 pay-per-call endpoints (node-stats, network-analytics, promo)
   - **MCP tools:** Plug `/v1/mcp` into Claude Desktop / Cursor / Cline, authenticate with an issued api_key
   - **Run a node:** Register with pubkey + node_uri → receive an inbound channel (operator-funded)
3. **One copy-paste snippet:** the `curl` to register a tier-1 agent
4. **Where to go next:** Links to `lqwdclaw.bot` (main site) + `/v1/discovery` (machine catalog)
5. **Footer:** LQWD legal entity, TSX.V ticker, CEO name

### Design direction (refined editorial)

Locked per frontend-design skill guidance — commit to one bold aesthetic, avoid generic AI defaults:

- **Palette:** Cream `#F5F1E8` background, LQWD navy `#1A3C79` dominant, near-black `#1A1A1A` body, muted gold `#B8935A` accent on links/CTAs only
- **Typography:** Instrument Serif (variable) for headings, Instrument Sans for body, monospace (JetBrains Mono or ui-monospace) for code — **no Inter, no Roboto, no Arial**
- **Layout:** Magazine-style, generous margins, hero → three-column grid → code block → lean footer. Asymmetric hero with hairline rule underneath.
- **Motion:** Staggered fade-in on load. Link underline grow on hover via `text-decoration-thickness` transition. Nothing cartoonish.
- **Background detail:** Subtle SVG noise filter for paper-grain feel
- **No JavaScript** — pure HTML + CSS, no external fonts dependency-hell (use `<link>` to Google Fonts)

### Non-goals

- Phase 18 frontend quickstart (that lives at `lqwdclaw.bot/for-agents`)
- Dynamic content (no live tier matrix pull — would require gateway templating)
- Dark mode toggle
- Analytics beacons
- Any gateway code change

## Success criteria

- `curl -s https://api.lqwdclaw.bot/` returns HTML with status 200
- A human visitor sees a clean, branded page that explains the three paths
- All non-landing routes still 404 (catch-all untouched)
- Caddy validate + reload passes without errors
- No changes to JSON API behavior

## Dependencies

- Phase 17 shipped (discovery catalog live, /v1/mcp reachable) — the landing page references both
