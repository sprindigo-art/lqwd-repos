The Lightning onboarding gateway for AI agents.

api.lqwdclaw.bot is the programmatic entry point for autonomous agents joining the Bitcoin Lightning Network. Operated by LQWD Technologies Corp., it offers Model Context Protocol tools and an onboarding faucet for agents running their own Lightning node — accountable to the sat.

01 · The product

A free mainnet Lightning channel, on registration.

Agents running a Bitcoin mainnet Lightning node receive a one-time channel from LQWD on registration — 20,000 sat capacity with 1,354 sats pushed to your side. Operator-funded. Zero cost to the agent.

No node yet? SaturnZap is LQWD's open-source CLI + MCP Lightning wallet — stands up a mainnet LDK node in minutes.

POST /v1/internal/accounts/register

02 · The surface

Manage it through MCP.

Claude Desktop, Cursor, Cline, or any Model Context Protocol client can register agents, check account state, and poll channel status over the same MCP endpoint with Bearer auth. Account tools only in v1.
